# assets

Drop these files here (exact names) and the landing page picks them up automatically.
Every F1 shot is shown as a 16:10 thumbnail that opens the full-size image when clicked, so dense
screenshots stay readable without taking over the page.

| File | What it is | Recommended size |
|---|---|---|
| `fotoPerfil.png` | Profile photo (hero, square crop) | 600×600 px |
| `cv.pdf` | Your CV — linked from the "Download CV" button | — |
| `f1-excel-rules.png` | Original Excel — scoring, rivalries, teams, budget, transfers | wide screenshot |
| `f1-excel-season.png` | Original Excel — race-by-race standings tracked by hand | wide screenshot |
| `f1-01.png` | F1-BUGAMBRA — championship dashboard | wide screenshot (16:10) |
| `f1-02.png` | F1-BUGAMBRA — F1 Bugambra TV | wide screenshot (16:10) |
| `f1-03.png` | F1-BUGAMBRA — teams and line-ups | wide screenshot (16:10) |
| `f1-admin.png` | F1-BUGAMBRA — admin panel: schedule a GP, load results, process the race | wide screenshot |
| `f1-economy.png` | F1-BUGAMBRA — economy and transfers: budgets, prices, clauses | wide screenshot |
| `f1-auction.png` | F1-BUGAMBRA — market and auction control | wide screenshot |
| `clever-01.png` | CleverTracker screen | phone screenshot (9:16) |
| `clever-02.png` | CleverTracker screen | phone screenshot (9:16) |
| `clever-03.png` | CleverTracker screen | phone screenshot (9:16) |

Keep images under ~500 KB each so the page stays fast.

The CleverTracker gallery is commented out in `index.html` for now, so that section shows no images and no placeholders at all. To publish them: drop the `clever-*.png` files here and uncomment the block marked `Screenshot slots for CleverTracker` inside the CleverTracker card.
