Configuración de Firebase (administración de la web)
  1. En Firebase Authentication, activa el proveedor Google.
  2. En Authentication → Settings → Authorized domains, comprueba que aparece ajgarciarias10.github.io.
  3. Crea la base de datos de Cloud Firestore y publica las reglas del archivo firestore.rules de este proyecto.

La configuración web de Firebase está en cuenta-config.js. Esos identificadores son públicos; las reglas de Firestore son las que impiden que una cuenta lea el progreso de otra.

Cómo se guarda y protege mi progreso

Tu plan de estudio, sesiones, tests, errores y competencias se guardan en Cloud Firestore, dentro del proyecto Firebase de esta aplicación, asociados a tu UID de Google. Las reglas limitan cada cuenta a sus propios datos; quien administra el proyecto Firebase puede administrar la base de datos.

La aplicación usa Google para identificarte. No solicita acceso a tus documentos ni a tus mensajes.

Al conectar puedes importar el progreso local del navegador si tu cuenta aún no tiene datos. En otros dispositivos, conecta la misma cuenta Google para recuperarlo. Los datos que guardaste anteriormente en Drive no se copian automáticamente: descarga el JSON de Drive y restaúralo aquí.

Durante el estudio verás si el progreso está guardado o pendiente de sincronizar. Antes de cerrar sesión, guarda los cambios pendientes. Cerrar sesión en esta web retira la copia local de la cuenta de este equipo.
